## 素材制作指南（PPT 即可完成）

### ① 系统架构图

**建议用 draw.io 或 PPT 画**，四层上下结构：

```
┌──────────────────────────────────────────┐
│           交互层 (Interaction)            │
│  PC 端 Qt5 UI (远程监护)    7" LCD Qt5 UI │
├──────────────────────────────────────────┤
│           通信层 (Communication)          │
│  WebRTC P2P (公网NAT穿透)                │
│  DataChannel + RTP  |  UART (115200)     │
│  Unix Socket / DMA-BUF SHM               │
├──────────────────────────────────────────┤
│           计算层 (Computation)            │
│  RK3588: NPU→AI推理  |  MPP→H264编码    │
│         Whisper+LLM  |  RGA→图像转换     │
│  STM32 MCU: 差速控制 |  0xAA 0x55帧协议  │
├──────────────────────────────────────────┤
│        感知与执行层 (Perception)          │
│  摄像头(V4L2)  |  麦克风  |  电机  |  舵机 │
└──────────────────────────────────────────┘
```

### ② 硬件实物照

- **MCU 板**：正反面各一张，标注 "自研 MCU 控制板"
- **RK3588 核心板 + 外围连接**：摄像头排线、串口线、7寸屏 FPC 排线
- **整车俯视图**：四轮底盘、电池、布线

```

① 主动式远程陪伴
监护者随时连接，老人零操作，不依赖被叫应答

无人连接时的 AI 陪聊，不是工具型助手，是情感陪伴

监护者能力强操作、老人端零负担，

```
系统参数

## 剪映操作步骤

### 第 1 步：创建项目，导入素材

```
1. 打开剪映 → 新建项目 → 选择 16:9 比例
2. 导入所有素材（视频 + 图片）
3. 将 PC 录屏拖入主轨道
```

### 第 2 步：粗剪——按分段标记时间点

```
1. 在时间轴上找到每个功能段的起点和终点
2. 用"分割"工具切开
3. 删除不需要的部分（如等待 ICE 连接的空白段）
4. 每个功能段用不同颜色的标记
```

### 第 3 步：添加画中画（PIP）和分屏

**机器人实拍画中画**：
```
1. 将机器人视频拖到"画中画"轨道
2. 缩小到屏幕右侧 1/4 大小
3. 添加白色边框（1px）
4. 调整位置：右上角或右下角
```

**同步时间轴**：
```
1. PC 录屏和机器人实拍是同步拍摄的
2. 对齐标志事件：比如 PC 点击"呼叫"的时刻 ≈ 机器人屏幕切 callPage 的时刻
3. 手动微调使两轨道对齐
```

### 第 4 步：添加字幕和标注

```
1. 文本 → 新建文本 → 输入字幕
2. 用"贴纸"功能做箭头和标注
3. 用"关键帧"做弹出动画（位置从下往上移动）
4. 阶段小结用"片头模板"做黑底白字全屏卡
```

### 第 5 步：添加转场和音效

```
1. 段落之间用"淡入淡出"转场（0.3 秒）
2. 功能切换用"闪白"过渡
3. 警告触发处可加音效（短促提示音）
4. 背景音乐全程低音量，口播时自动闪避
```

### 第 6 步：片头片尾制作

```
片头：
1. 使用"片头模板"或手动做黑底白字
2. 标题文字用关键帧做缩放动画（从小到大）
3. 硬件照片快速切换（每张 0.8 秒 + 闪白过渡）

片尾：
1. 黑底白字滚动字幕
2. 背景音乐淡出
```

### 第 7 步：导出

```
1. 分辨率：1920×1080
2. 帧率：30fps
3. 码率：推荐 8-12 Mbps
4. 格式：MP4 (H.264)
```

## 音频方案

### 背景音乐

- 选轻钢琴或 acoustic 风格，无版权
- 剪映自带音乐库搜索 "technology gentle" 或 "hopeful"
- 音量设为原始音量的 25%-30%

### 旁白

- 方案 A：自己录音，逐段配
- 方案 B：剪映"文本朗读"功能（AI 配音），选自然男声
- 建议先用 AI 配音做初版，听效果再决定是否改录音

## 建议时间分配（比赛通常 3-5 分钟限制）

| 段落 | 时长 | 占比 |
|------|------|------|
| 片头 | 15s | 7% |
| 通话+控制 | 55s | 27% |
| AI 追踪 | 35s | 18% |
| 火灾/跌倒 | 45s | 23% |
| 语音对话 | 25s | 13% |
| 总结+片尾 | 25s | 13% |
| **总计** | **3:20** | |

如果比赛要求 5 分钟，把 AI 检测段和语音对话段各多给 15-20 秒操作特写。
