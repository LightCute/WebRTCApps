# 居家陪护机器人 — 演示视频拍摄脚本

## 基本信息

- **时长**: 3-4 分钟
- **拍摄方式**: 一镜到底（实时操作，单镜头拍完）
- **拍摄设备**: 手机/相机固定机位，能同时拍到机器人 + PC 屏幕
- **道具准备**: 打火机（火灾模拟）、软垫（跌倒模拟）、WiFi + 手机热点（跨网段）

---

## 拍摄机位

```
         ┌─────────────┐
         │   PC 屏幕    │
         │  (监护端UI)  │      ┌─────────────────┐
         └──────┬──────┘      │    机器人        │
                │              │  (7寸屏 + 底盘)  │
        ┌───────┴───────┐      └────────┬────────┘
        │    拍摄设备    │               │
        │   (三脚架)     │ ← →  操作者半身出镜
        └───────────────┘
```

## 拍摄前检查清单

### 设备
- [ ] 机器人底盘满电
- [ ] RK3588 启动正常，摄像头、麦克风、7寸屏正常工作
- [ ] PC 端网络通畅（手机热点 / 不同 WiFi）
- [ ] 拍摄设备满电、存储空间充足
- [ ] 三脚架固定好，机位已确认

### 软件
- [ ] 信令服务器已启动（120.79.210.6:8888）
- [ ] 机器人端 `client_arm64` daemon 正常启动
- [ ] 机器人端 `ui_rk` 正常启动，QSS 加载正确
- [ ] PC 端 `ui_x64` 正常启动，已连接服务器
- [ ] AI 模型文件在正确路径（models/ 目录）
- [ ] 串口 `/dev/ttyS9` 已连接 MCU

### 道具
- [ ] 打火机（火灾模拟）
- [ ] 软垫（跌倒模拟用）
- [ ] 测试用对话内容（语音对话环节）

### 排练
- [ ] 完整走一遍脚本，确认每个功能不卡壳
- [ ] 确认 ICE 连接耗时（应在 5 秒内）
- [ ] 确认追踪响应及时（转向延迟 <500ms）
- [ ] 确认告警弹出及时（检测到后 <1 秒）

## 系统架构速览

```
┌─────────────────────────────────────────────────────────┐
│                      PC 端 (x64)                        │
│  qt_ui_x64 ─── client_x64 (WebRTC) ─── 信令服务器       │
│      │               │                    (公网)        │
│  键盘控制          RTP 音视频                           │
│  DataChannel      SHM 视频帧                            │
└──────────────────────┼──────────────────────────────────┘
                       │  Internet
┌──────────────────────┼──────────────────────────────────┐
│              机器人端 (RK3588)                           │
│                                                         │
│  ui_rk ─── client_arm64 (WebRTC)                        │
│    │           │                                        │
│    ├─ SerialWorker → /dev/ttyS9 → MCU → 电机/舵机       │
│    ├─ AiReceiver ← AI 推理进程 (RKNN/NPU)               │
│    ├─ VoiceChatManager → Whisper + LLM                 │
│    └─ DmaBufVideoSource ← DMA-BUF ← 摄像头 (V4L2)      │
│                                                         │
│  RGA 硬件: YUYV→NV12→I420 零拷贝转换                    │
│  MPP 硬件: H264 编解码                                   │
└─────────────────────────────────────────────────────────┘
```
