# 居家陪护机器人 — 演示视频拍摄脚本

## 基本信息

- **时长**: 3-4 分钟（总时长约 3:20）
- **拍摄方式**: 一镜到底，单台拍摄设备，相机**平移 + 推拉**切换画面
- **拍摄设备**: 手机/相机（手持或三脚架，不要固定——需要移动）
- **道具**: 打火机（火灾模拟）、软垫（跌倒模拟）、手机热点 + WiFi（跨网段）

---

## 核心拍摄思路：三阶段，画面引导观众视线

不是用两个机位同时拍再同框——而是**一台相机，三个阶段，连续移动**。

```
阶段1 ────────────→ 阶段2 ────────────→ 阶段3
近距离机器人       平移180°到PC        后退拉远同框
(~80秒)           (~80秒)            (~40秒)

   📷              ┌───PC──┐             📷(后退)
  (近景)           │       │           ╱
   │               └───────┘    [机器人]──[PC]
 [机器人]              ↑
                   📷(近景)
```

---

## 机位移动路线

```
起点: 相机在机器人左前方 0.5m，拍机器人屏幕+底盘
  │
  ├─ 阶段1 全程在这里，近景展示机器人端所有功能
  │
  ├─ → → 相机慢慢平移 180°（约 5 秒），背景虚化过渡
  │
  ├─ 阶段2 停在 PC 桌面前方 0.5m，近景展示 PC 端所有功能
  │
  └─ → → 相机慢慢后退（约 5 秒），拉远成全景
     │
     终点: 机器人在左、PC 在右，同时入画，展示协同效果
```

## 拍摄前准备

### 设备检查

- [ ] 机器人底盘满电
- [ ] RK3588：摄像头、麦克风、7 寸屏正常
- [ ] PC 端：网络通畅（手机热点 vs WiFi，不同网段）
- [ ] 拍摄设备满电，存储 >10GB
- [ ] 如果手持不稳：用带轮子的三脚架，方便平移

### 软件检查

- [ ] 信令服务器已启动（120.79.210.6:8888）
- [ ] 机器人端 `client_arm64` daemon 正常
- [ ] 机器人端 `ui_rk` 全屏启动，QSS 正确
- [ ] PC 端 `ui_x64` 启动，已连接服务器
- [ ] AI 模型文件在 models/ 路径下
- [ ] `/dev/ttyS9` 串口连接 MCU

### 道具准备

- [ ] 打火机（火灾模拟）
- [ ] 软垫（跌倒模拟用，防摔）
- [ ] 测试用对话内容
- [ ] 助手 1 人（配合走动 / 跌倒 / 点火 / 说话）

### 排练要点

- [ ] 相机平移路线走 3 遍，避免碰倒东西
- [ ] ICE 连接时间 <5 秒（排练时测好）
- [ ] AI 追踪响应 <500ms（提前验证）
- [ ] 告警弹出 <1 秒
- [ ] 语音对话回复 <3 秒
- [ ] 全程口播或后期配字幕——提前写好逐字稿

## 系统架构速览

```
┌───────────────────────────────────────────────────────────┐
│                       PC 端 (x64)                         │
│   qt_ui_x64 ─── client_x64 (WebRTC) ─── 信令服务器        │
│       │              │                    (公网)          │
│   WASD/IJKL    RTP 音视频                                 │
│   DataChannel  SHM 视频                                   │
└───────────────────────┼───────────────────────────────────┘
                        │  Internet
┌───────────────────────┼───────────────────────────────────┐
│               机器人端 (RK3588)                            │
│                                                           │
│   ui_rk ─── client_arm64 (WebRTC)                         │
│     │           │                                         │
│     ├─ SerialWorker → /dev/ttyS9 → MCU → 电机 / 舵机      │
│     ├─ AiReceiver ← AI 推理 (RKNN / NPU)                  │
│     ├─ VoiceChatManager → Whisper + LLM                   │
│     └─ DmaBufVideoSource ← DMA-BUF ← 摄像头 (V4L2)       │
│                                                           │
│   RGA 硬件: YUYV→NV12→I420 零拷贝                         │
│   MPP 硬件: H264 编解码                                    │
│   自研 MCU 协议: 0xAA 0x55 帧封装                          │
└───────────────────────────────────────────────────────────┘
```
